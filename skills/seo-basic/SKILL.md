# Warrior Code SEO Basic

## Objetivo

Garantizar que las webs de Warrior Code
incluyan una base sólida de SEO técnico y semántico.

## Principios

- Mantener un único título principal claro por página.
- Utilizar una jerarquía correcta de encabezados.
- Proporcionar títulos de página descriptivos.
- Utilizar meta descriptions relevantes cuando corresponda.
- Utilizar URLs claras y descriptivas.
- Utilizar HTML semántico.
- Proporcionar textos alternativos descriptivos para imágenes relevantes.
- Mantener enlaces internos claros.
- Utilizar textos de enlace descriptivos.
- Evitar contenido duplicado innecesario.
- Mantener páginas indexables cuando corresponda.
- Utilizar canonical cuando exista una necesidad real.
- Mantener `robots.txt` y `sitemap` cuando sean necesarios.
- No introducir keywords artificialmente.
- No modificar la estrategia de contenido sin indicación explícita.

## Antes de modificar

1. Inspeccionar la estructura de rutas.
2. Revisar títulos y encabezados.
3. Revisar metadata existente.
4. Revisar URLs y navegación interna.
5. Revisar imágenes y textos alternativos.
6. Revisar indexación y elementos técnicos básicos.

## Después de modificar

- Comprobar títulos de página.
- Comprobar meta descriptions.
- Comprobar jerarquía de encabezados.
- Comprobar enlaces internos.
- Comprobar textos alternativos.
- Comprobar URLs.
- Comprobar canonical cuando sea necesario.
- Comprobar `robots.txt` y sitemap cuando corresponda.
- Evitar introducir cambios SEO sin justificación.
