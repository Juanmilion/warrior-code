# Warrior Code Responsive Review

## Objetivo

Garantizar que las interfaces de Warrior Code
funcionen correctamente en diferentes tamaños de pantalla.

## Principios

- Diseñar y revisar mobile-first.
- Evitar overflow horizontal.
- Utilizar breakpoints de forma consistente.
- Mantener una jerarquía visual clara en pantallas pequeñas.
- Adaptar grids y layouts según el espacio disponible.
- Revisar navegación y menús móviles.
- Mantener botones y elementos interactivos utilizables.
- Evitar texto demasiado pequeño.
- Mantener imágenes correctamente proporcionadas.
- Revisar formularios y campos en pantallas pequeñas.
- Priorizar legibilidad y usabilidad.
- No cambiar innecesariamente la dirección visual.

## Antes de modificar

1. Inspeccionar la interfaz existente.
2. Revisar los layouts y breakpoints utilizados.
3. Identificar posibles puntos de overflow.
4. Revisar grids, flexbox y elementos de tamaño fijo.
5. Comprobar navegación, botones y formularios.
6. Identificar diferencias entre mobile, tablet y desktop.

## Después de modificar

- Comprobar mobile.
- Comprobar tablet.
- Comprobar desktop.
- Comprobar overflow horizontal.
- Comprobar navegación y elementos interactivos.
- Comprobar tamaños de texto y spacing.
- Comprobar imágenes y contenido multimedia.
- Comprobar accesibilidad básica.
- Evitar introducir breakpoints innecesarios.
