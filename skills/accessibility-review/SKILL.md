# Warrior Code Accessibility Review

## Objetivo

Revisar interfaces de Warrior Code
para detectar y corregir problemas básicos de accesibilidad.

## Principios

- Utilizar HTML semántico.
- Mantener una jerarquía correcta de encabezados.
- Proporcionar nombres accesibles a elementos interactivos.
- Mantener contraste suficiente entre texto y fondo.
- No depender únicamente del color para transmitir información.
- Mantener estados hover, focus y disabled claramente diferenciados.
- Garantizar navegación mediante teclado.
- Utilizar labels correctamente asociados a los campos de formulario.
- Proporcionar textos alternativos adecuados para imágenes relevantes.
- Evitar elementos interactivos no semánticos.
- Mantener tamaños de interacción adecuados.
- Respetar preferencias de reducción de movimiento cuando sea necesario.
- No introducir soluciones de accesibilidad innecesariamente complejas.

## Antes de modificar

1. Inspeccionar la estructura semántica existente.
2. Revisar encabezados y landmarks.
3. Revisar elementos interactivos.
4. Revisar formularios y sus labels.
5. Revisar imágenes y textos alternativos.
6. Revisar contraste, focus y navegación mediante teclado.

## Después de modificar

- Comprobar navegación mediante teclado.
- Comprobar estados focus.
- Comprobar labels y formularios.
- Comprobar textos alternativos.
- Comprobar jerarquía de encabezados.
- Comprobar contraste.
- Comprobar elementos interactivos.
- Comprobar responsive.
- Evitar introducir atributos ARIA innecesarios.
