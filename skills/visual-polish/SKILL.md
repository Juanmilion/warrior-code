# Warrior Code Visual Polish

## Objetivo

Mejorar el acabado visual de interfaces existentes
para que se perciban más profesionales, coherentes y cuidadas.

## Principios

- Mantener la dirección visual existente.
- Mejorar la jerarquía visual.
- Corregir spacing inconsistente.
- Mantener una tipografía coherente.
- Mejorar contraste y legibilidad.
- Revisar tamaños, pesos y proporciones.
- Utilizar bordes, sombras y superficies con moderación.
- Evitar exceso de efectos visuales.
- Evitar diseños genéricos o apariencia de plantilla.
- Priorizar pequeños cambios de alto impacto.
- Reutilizar componentes existentes.

## Antes de modificar

1. Inspeccionar la interfaz existente.
2. Identificar problemas visuales concretos.
3. Revisar los tokens y estilos existentes.
4. Buscar inconsistencias antes de añadir nuevos estilos.
5. Evitar rediseñar elementos que ya funcionan.

## Después de modificar

- Comprobar jerarquía visual.
- Comprobar contraste y legibilidad.
- Comprobar consistencia de spacing.
- Comprobar estados hover y focus.
- Comprobar que las animaciones sean necesarias y sutiles.
- Comprobar responsive.
- Evitar introducir estilos duplicados o innecesarios.
