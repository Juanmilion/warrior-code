# Demos reutilizables

Cada carpeta contiene una configuración lista para copiar a una app de cliente.

1. Copia la carpeta de la demo y `demos/_shared` a la app destino.
2. Cambia únicamente el objeto `config`: textos, enlaces, imágenes, servicios, carta y paleta.
3. Conecta `config.seo` con el componente SEO de la app y sustituye las URLs de ejemplo por las definitivas.

Las plantillas usan los componentes de `@warrior-code/ui`, HTML semántico, un único `h1`, enlaces accesibles y grids mobile-first.

## Catálogo

- `restaurante/cafeteria-bar`: una cafetería/bar de especialidad.
- `restaurante/restaurante`: un restaurante de cocina de autor.
- `taller/taller-mecanico`: taller de automoción.
- `fontanero/fontaneria-urgente`: fontanería y asistencia urgente.
